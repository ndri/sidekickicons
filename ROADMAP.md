# Roadmap

Icons to add next, roughly in order. Demand is the votes on matching
[Heroicons discussions](https://github.com/tailwindlabs/heroicons/discussions), added up across duplicates
(counted in October 2026). Heroicons hasn't added icons since 2.2.0, so none of these exist there.

  `strikethrough`, `arrow-up-on-square` (share), `trophy`, `wrench`, `wallet`
- Rotating left and right: `arrow-path-single-clockwise` and `arrow-path-single-counterclockwise`
